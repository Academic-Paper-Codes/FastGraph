FastGraph: Fast Large-scale Directed Social Network Graph Generation

This project is for the fast generation of directed social network graphs with reciprocal edges and high clustering.

FastGraph.py: Generate directed social network graphs

Analysis.py: Analyse topological features (17 metrics)

SIR.py: Simulate a basic discrete SIR model

Hyperparameters.docx: Input parameters

The following libraries need to be installed for the execution of the notebooks:
- Python version 3.8.5
- conda install -c anaconda numpy
- conda install -c anaconda pandas
- conda install -c conda-forge matplotlib
- conda install -c anaconda networkx
- conda install -c trentonoliphant datetime
- conda install -c anaconda scipy
- pip install EoN
